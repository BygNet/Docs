## Add an image to Gallery

1. Sign in and open [Create](https://byg.gg/#create).
2. Choose **Add Image**.
3. Enter a title.
4. Paste the image's direct public URL.
5. Select **Upload**.

The image is saved to your Byg Gallery. Browse published images at [Gallery](https://byg.gg/gallery).

## Get the correct image URL

Byg needs the file URL, not the hosting website's viewer page.

1. Upload the image to an image host.
2. Copy **Direct link**, **Direct URL**, or **Image URL**.
3. Open the copied URL in a new browser tab.
4. Confirm that the tab displays only the image. If it opens a page with buttons or comments, copy the direct link instead.
5. Paste that URL into Byg Gallery or Markdown.

The URL should use `https://`. It may end in `.jpg`, `.png`, `.gif`, or `.webp`, but an extension is not required if the URL serves the image directly.

## Free hosting and image CDN options

Free limits and policies change, so check each provider before relying on it for important images:

- [Cloudinary](https://cloudinary.com/pricing) — image hosting, transformations, optimization, and CDN delivery. Its URL format is documented [here](https://cloudinary.com/documentation/image_transformations).
- [ImageKit](https://imagekit.io/docs/overview) — image storage, optimization, transformations, and CDN delivery. See its [CDN documentation](https://imagekit.io/docs/cdn-caching-and-purging).
- [ImgBB](https://imgbb.com/) — simple free image hosting with direct links. Its [official API](https://api.imgbb.com/) also returns image URLs.

Do not upload private or sensitive images to a public host. Keep a copy of anything you may need to restore later.
