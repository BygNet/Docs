## Create a post

1. Sign in to Byg.
2. Open [Create](https://byg.gg/#create) and choose **Write Post**.
3. Enter a title and write the body in the editor.
4. Use the toolbar for formatting, lists, headings, code, and links. The link button lets you enter display text and the destination URL.
5. Select **Preview** to check the rendered post.
6. Select **Post** to publish it.

For a Markdown link, use:

```md
[display text](https://example.com)
```

To embed an image, use a direct public image URL:

```md
![description](https://example.com/image.jpg)
```

See [Add images](/web/images) if you need a public image URL.
