## Byg Features
Lots of new features are being planned to be added to Byg.
They are listed here:

<Accordion title="Creating Posts">
  Adding posts on Byg Web is coming very soon.
  This will allow all users to publish their text content on Byg Web very easily.
</Accordion>

<Accordion title="Uploading Images">
  Users will be able to upload images directly from the web interface.
  This feature will support high-quality images and seamless sharing across the platform.
</Accordion>

<Accordion title="Comments">
  Commenting on posts and images will allow users to engage in discussions
  and interact more deeply with content across Byg.
</Accordion>

<Accordion title="Link Collections">
  Users will be able to create curated collections of links,
  making it easy to organize and share resources with others.
</Accordion>

<Accordion title="Enhanced Profiles">
  Profiles will be expanded with greatly.
  They will represent your online identity and information, including:
  - Bios
  - Display names
  - Profile pictures
  - Banners
  - User posts
</Accordion>

<Accordion title="Clan Badges">
  Clan badges will be automatically assigned based on a user's email domain,
  helping communities and teams identify each other on the platform.
</Accordion>

<Accordion title="Account Security">
  Enhanced security features such as two-factor authentication will be added
  to better protect user accounts.
</Accordion>

<Accordion title="Byg Shop Expansion">
  More shops and items will be introduced to the Byg Shop,
  offering users a wider variety of content and products.
</Accordion>

<Accordion title="Direct Messages">
  Direct messaging will allow users to communicate privately with each other,
  enabling real-time conversations on Byg.
</Accordion>
