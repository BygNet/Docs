## Enable 2FA

1. Open [Security settings](https://byg.gg/settings#security).
2. In the **Authenticator App** section, select **Generate Setup Key**.
3. Scan the setup link with your authenticator app, or copy the manual entry key.
4. Enter the six-digit code generated by the app.
5. Select **Enable 2FA**.

Store the manual entry key somewhere safe before finishing setup. You need access to the authenticator app when you log in.

## Disable 2FA

Return to [Security settings](https://byg.gg/settings#security) and select **Disable 2FA**. You can generate a new setup key later to enable it again.
